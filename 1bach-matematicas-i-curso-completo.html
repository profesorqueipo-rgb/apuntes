Los reales son densos: entre dos números reales distintos siempre hay infinitos reales (por ejemplo, su punto medio, y el punto medio de este con uno de ellos, y así sin fin). Lo mismo pasa con los racionales y con los irracionales.

¿Existen de verdad los irracionales? 2 no es una fracciónSupongamos que sí lo fuera: 2 = ab con la fracción ya simplificada (a y b no son los dos pares).
Elevando al cuadrado: 2 = a2b2, es decir, a2 = 2b2. Entonces a2 es par, y por tanto a es par (el cuadrado de un impar es impar). Escribimos a = 2k.
Sustituyendo: 4k2 = 2b2 → b2 = 2k2, así que b2 es par y b también es par.
Pero habíamos dicho que la fracción estaba simplificada: contradicción. La suposición era falsa, así que 2 es irracional.
Este razonamiento, «supongo lo contrario y llego a algo imposible», se llama reducción al absurdo.

1.3 · Representar números en la recta

Los enteros se colocan directamente. Los racionales y las raíces cuadradas se pueden situar de forma exacta con regla y compás. [p. 3-4]

Una fracción: teorema de TalesEjemplo: 73 = 2 + 13: está entre 2 y 3, a un tercio del 2.
1) Desde el 2 se traza una semirrecta oblicua cualquiera.
2) Con el compás se marcan sobre ella 3 segmentos iguales (tantos como el denominador).
3) Se une la última marca con el 3.
4) Por las otras marcas se trazan paralelas a esa recta: dividen [2, 3] en 3 partes iguales.
Una raíz cuadrada: teorema de PitágorasSe busca un triángulo rectángulo cuya hipotenusa mida la raíz: c = a2 + b2.
2: catetos 1 y 1, porque 12 + 12 = 2.
5: catetos 2 y 1, porque 22 + 12 = 5.
17: catetos 4 y 1, porque 42 + 12 = 17.
Se levanta el cateto vertical en el extremo del horizontal, se traza la hipotenusa y con el compás (centro en 0) se lleva su longitud al eje.
¿Y si no es suma de dos cuadrados?Se encadenan triángulos. 11 no es suma de dos cuadrados de enteros, pero 11 = 32 + (2)2: primero se construye 2 y luego se usa como cateto vertical sobre el 3.

1.5 · Potencias y notación científica

Potencia de exponente naturalan = a · a · … · a (n veces)   23 = 2 · 2 · 2 = 8
a es la base, n el exponente y el resultado, la potencia.
Propiedadesan · am = an+m   an : am = an−m
an · bn = (a · b)n   an : bn = (a : b)n
(an)m = an·m
¿Por qué a0 = 1 y a−n = 1/an?No son reglas nuevas: son lo único que hace que la propiedad del cociente siga funcionando.
Por un lado a3 : a3 = 1 (un número entre sí mismo) y por otro a3 : a3 = a3−3 = a0. Luego a0 = 1.
Igual: a2 : a5 = a · aa · a · a · a · a = 1a3 y también a2 : a5 = a−3. Luego a−n = 1an, y (ab)−n = (ba)n.

1.6 · Radicales

Definicióna = b ⟺ bn = a   n es el índice y a el radicando. [p. 7]
Si n es par, solo existe para a ≥ 0 (ningún número elevado a un exponente par da negativo) y si a > 0 hay dos raíces opuestas: 81 = ±3.
Si n es impar, existe siempre y tiene el signo del radicando: −1000 = −10.
Potencias de exponente fraccionario: am = am/n¿Qué debería significar 52/3? Si las propiedades de las potencias siguen valiendo, (52/3)3 = 52: es el número que al cubo da 52, es decir, 52.
Por eso todo radical es una potencia y las propiedades de los radicales son las de las potencias: 25 = 52 = 52/3

1.8 · Intervalos, semirrectas y entornos

Como entre dos reales hay infinitos, para hablar de «todos los números entre a y b» usamos intervalos. [p. 13]

NombreNotaciónConjuntoRecta
Abierto(a, b){x ∈ ℝ / a < x < b}
Cerrado[a, b]{x ∈ ℝ / a ≤ x ≤ b}
Semiabiertos(a, b] · [a, b){x / a < x ≤ b} · {x / a ≤ x < b}
Semirrectas(a, +∞) · (−∞, a]{x / x > a} · {x / x ≤ a}

En ±∞ el paréntesis siempre es abierto: ∞ no es un número.

EntornosEl entorno de centro a y radio r (r > 0) son los puntos que están a menos de r de a:
E(a, r) = {x ∈ ℝ / d(x, a) < r} = {x ∈ ℝ / |x − a| < r} = (a − r, a + r)
El entorno cerrado admite la distancia r: E[a, r] = {x / |x − a| ≤ r} = [a − r, a + r].
Al revés, un intervalo es un entorno de centro su punto medio y radio la mitad de su longitud: (a, b) = E(a + b2, b − a2).
Pasa de entorno a intervalo y al revés Ejercicio de GuillermoE(13, 14) = (13 − 14, 13 + 14) = (112, 712)
(−32, 25): centro −32 + 252 = −1120, radio 25 + 322 = 1920 → E(−1120, 1920) [p. 15]

Unión A ∪ B («o»): los que están en A, en B o en los dos. Intersección A ∩ B («y»): los que están a la vez en A y en B. [p. 14]

Ejemplo (libro, ej. 64)A = (−2, 5], B = (−∞, 2], C = [0, 7)
A ∩ C = [0, 5] · A ∪ C = (−2, 7) · A ∪ (A ∩ C) = (−2, 5]
(A ∪ B) ∩ (A ∪ C) = (−∞, 5] ∩ (−2, 7) = (−2, 5]  el −2 no está en A ∪ C: el paréntesis es abierto

1.9 · Valor absoluto y distancia

Definición|a| = a  si a ≥ 0−a  si a < 0
Es la distancia de a al 0: |3| = |−3| = 3.
La distancia entre dos números es d(a, b) = |b − a| = |a − b|.
Para resolver|x| = k → x = k o x = −k
|x − a| < r ⟺ a − r < x < a + r (a menos de r de a)
|x − a| > r ⟺ x < a − r o x > a + r (a más de r de a)

Para escribir una expresión con valor absoluto sin las barras, se busca el punto crítico (donde lo de dentro vale 0) y se estudia el signo a cada lado. [p. 14-15]

Quitar las barras: punto crítico Ejemplo de Guillermo|2x − 3| + 4x. Punto crítico: 2x − 3 = 0 ⟺ x = 32.
Si x ≥ 32, lo de dentro es positivo y las barras no cambian nada: 2x − 3 + 4x = 6x − 3.
Si x < 32, es negativo y las barras le cambian el signo: −2x + 3 + 4x = 2x + 3.
|2x − 3| + 4x = 2x + 3  si x < 3/26x − 3  si x ≥ 3/2
¡OJO!

x2 = |x|, no x: (−3)2 = 3. Por eso (x + 2)2 = 4 tiene dos soluciones: |x + 2| = 4 → x = 2 o x = −6. [Llanera]

1.10 · Aproximaciones y errores

Cuando un número tiene infinitas cifras (o demasiadas), lo sustituimos por una aproximación y escribimos ≈, nunca =. [p. 15]

Tres formas de aproximarPor defecto (truncar): se cortan las cifras; queda por debajo.
Por exceso: se sube la última cifra; queda por encima.
Redondeo: la más cercana de las dos (si la cifra siguiente es 5 o más, por exceso).
π = 3,14159… a las milésimas: defecto 3,141 · exceso 3,142 · redondeo 3,142
a las diezmilésimas: defecto 3,1415 · exceso 3,1416 · redondeo 3,1416
ErroresError absoluto: la distancia entre el valor real x y la aproximación a: Ea = |x − a|.
Error relativo: el error por cada unidad del valor real, normalmente en %: Er = Ea|x|.
Al redondear a una cifra, el error absoluto es como mucho media unidad de esa cifra: es la cota del error.
¿Por qué hace falta el error relativo?Equivocarse en 1 al aproximar 11 por 10 no es lo mismo que equivocarse en 1 al aproximar 1 000 001 por 1 000 000: el error absoluto es 1 en los dos casos, pero Er = 111 ≈ 9 % frente a Er = 11000001 ≈ 0,0001 %. [Llanera]
EjemploAproximamos 13 ≈ 0,33: Ea = |13 − 33100| = 1300 ≈ 0,0033 · Er = 130013 = 1100 = 1 %

2.3 · Teorema del resto, Ruffini y factorización

Teorema del restoEl resto de dividir P(x) entre (x − a) es P(a).
Demostración: al dividir entre un polinomio de grado 1, el resto es un número R: P(x) = (x − a) · C(x) + R. Sustituyendo x = a, el primer sumando se anula: P(a) = 0 · C(a) + R = R.
Teorema del factor(x − a) divide a P(x) ⟺ P(a) = 0, es decir, ⟺ a es raíz de P.
Si R = 0, P(x) = (x − a) · C(x): hemos sacado un factor.

Regla de Ruffini: es una forma rápida de dividir, solo para divisores de la forma (x − a). Se bajan los coeficientes (¡con un 0 en los términos que faltan!), y en cada paso se multiplica por a y se suma. [p. 18]

3.6 · Resolución de triángulos

Resolver un triángulo es calcular sus tres lados y sus tres ángulos a partir de tres datos (al menos uno, un lado). Notación: el lado a está enfrente del ángulo A, b enfrente de B y c enfrente de C. Siempre A + B + C = 180°. [p. 58]

Triángulos rectángulosBasta con las razones trigonométricas y Pitágoras. Además, la altura sobre la hipotenusa forma dos triángulos semejantes al grande, y de las proporciones salen:
teorema del cateto: c2 = a · m, b2 = a · n  (cm = ac)
teorema de la altura: h2 = m · n  (mh = hn)
donde m y n son las proyecciones de los catetos sobre la hipotenusa a. [p. 60]
Teorema del senoLa altura h sale de dos triángulos rectángulos: h = c sen B y h = b sen C. Igualando, bsen B = csen C. Con otra altura se llega igual a a:
asen A = bsen B = csen C [p. 58]
Teorema del cosenoCon la figura: c2 = h2 + m2 y b2 = h2 + n2, así que c2 − m2 = b2 − n2.
c2 = b2 + m2 − n2 = b2 + (m + n)(m − n) = b2 + a(a − 2n) = a2 + b2 − 2an
y como n = b cos C: c2 = a2 + b2 − 2ab cos C. Igual con los otros lados:
a2 = b2 + c2 − 2bc cos A · b2 = a2 + c2 − 2ac cos B
Si C = 90°, cos C = 0 y queda Pitágoras: es su generalización. [p. 59-60]
¿Cuál uso?Dos ángulos y un lado: el tercer ángulo por la suma y los lados con el teorema del seno.
Dos lados y el ángulo que forman: el tercer lado con el del coseno.
Tres lados: los ángulos con el del coseno (despejando el coseno).
Dos lados y el ángulo opuesto a uno: teorema del seno, con cuidado (ver ¡OJO!).

4.1 · ¿Por qué hacen falta?

La ecuación x2 + 1 = 0 no tiene solución real: ningún número real elevado al cuadrado da −1. 5.1 · Vectores en el plano

Vectores fijos y libresUn vector fijo AB→ es un segmento orientado de origen A y extremo B. Tiene módulo (longitud), dirección (la de su recta) y sentido (de A a B).
Dos vectores fijos son equipolentes si tienen el mismo módulo, dirección y sentido. Un vector libre v→ es el conjunto de todos los equipolentes a uno: lo podemos dibujar donde queramos.
Coordenadas: con A(x₁, y₁) y B(x₂, y₂), AB→ = (x₂ − x₁, y₂ − y₁)  (extremo menos origen). [p. 74]
Módulo|v→| = v₁2 + v₂2 (Pitágoras).
Un vector es unitario si su módulo es 1. Para normalizar v→ (obtener uno unitario con su misma dirección y sentido) se divide entre su módulo: v→|v→|. [p. 75, 77]
OperacionesSuma: u→ + v→ = (u₁ + v₁, u₂ + v₂) (regla del paralelogramo).
Resta: u→ − v→ = (u₁ − v₁, u₂ − v₂).
Producto por un número k: kv→ = (kv₁, kv₂): misma dirección, módulo multiplicado por |k|, mismo sentido si k > 0 y opuesto si k < 0. [p. 75]
Combinación lineal y basew→ es combinación lineal de u→ y v→ si w→ = αu→ + βv→ para algunos números α, β.
Varios vectores son linealmente dependientes si alguno es combinación lineal de los demás; si no, son independientes. Dos vectores del plano son dependientes cuando son paralelos: u→ = kv→, es decir, u₁v₁ = u₂v₂.
Dos vectores independientes forman una base: cualquier otro vector se escribe como combinación lineal de ellos, y de una sola manera. La base canónica es i→ = (1, 0), j→ = (0, 1): (2, −3) = 2i→ − 3j→ [p. 76]

A.1 · Lugares geométricos y cónicas

Un lugar geométrico es el conjunto de puntos del plano que cumplen una propiedad. Ya conocemos dos: la mediatriz (puntos a igual distancia de dos puntos) y la bisectriz (a igual distancia de dos rectas). Para hallar su ecuación se escribe la propiedad con un punto genérico X(x, y) y se opera.

Las cónicas son las curvas que salen al cortar un cono con un plano: si el plano es paralelo a la base, una circunferencia; si se inclina, una elipse; si es paralelo a una generatriz, una parábola; y si es más vertical, una hipérbola. Todas tienen ecuaciones de segundo grado en x e y. [Llanera, 4]

A.2 · Circunferencia

Definición y ecuaciónEs el lugar de los puntos a distancia r (radio) de un punto C(a, b) (centro):
d(C, X) = r ⟺ (x − a)2 + (y − b)2 = r
(x − a)2 + (y − b)2 = r2
Desarrollando sale la forma x2 + y2 + Dx + Ey + F = 0, con D = −2a, E = −2b, F = a2 + b2 − r2.
Al revés: ¿es una circunferencia?Los coeficientes de x² e y² tienen que ser iguales (y se dividen para que valgan 1) y no puede haber término en xy. Luego se completan cuadrados:
x2 + y2 − 4x − 4y + 3 = 0 → (x − 2)2 − 4 + (y − 2)2 − 4 + 3 = 0 → (x − 2)2 + (y − 2)2 = 5
Centro (2, 2) y radio 5. Si a la derecha sale un número negativo o 0, no es una circunferencia (o es un solo punto).

dos puntos, d < r: secante · un punto, d = r: tangente · ninguno, d > r: exterior.
La tangente en un punto P es perpendicular al radio CP: el vector CP es su vector normal.

A.5 · Parábola

Definición y ecuaciónEs el lugar de los puntos que están a la misma distancia de un punto F (foco) y de una recta d (directriz). El vértice está a mitad de camino entre ambos y p es la distancia del foco a la directriz.

Las parábolas de funciones y = ax2 + bx + c son de este tipo.
EjemplosFoco F(2, 0), directriz x = −2: p = 4 → y2 = 8x

7.1 · Qué es una sucesión

DefiniciónUna sucesión es una lista ordenada e infinita de números: a1, a2, a3, …, an, …. Cada uno es un término; an es el término general (el que ocupa el lugar n).
Es una función cuyo dominio son los números naturales: a cada lugar n le corresponde el número an. [p. 114]
Formas de definirla1) Por una propiedad: los números pares 2, 4, 6, 8…; los primos 2, 3, 5, 7, 11…
2) Por su término general: an = 3n2 + 3 → 6, 15, 30, 51…
3) Por recurrencia (cada término a partir de los anteriores): Fibonacci a1 = a2 = 1, an = an−1 + an−2 → 1, 1, 2, 3, 5, 8, 13, 21, 34…
4) A veces no se puede de ninguna de estas formas. [p. 114]
Actividades de clasea1 = 2, a2 = 5, an = 3an−1 + 2an−2 → 2, 5, 19, 67, 239, …
Término general de 0, 3, 8, 15, 24, 35…: cada uno es un cuadrado menos 1 → an = n2 − 1 (por recurrencia, an = an−1 + (2n − 1))
Término general de 12, 35, 510, 717, 926…: numeradores impares, denominadores «cuadrado + 1» → an = 2n − 1n2 + 1
6, 18, 54, 162… → 6 · 3n − 1 · 3, 2, 53, 64, 75… → n + 2n · 7; 0,7; 0,07… → 7 · 0,1n − 1 [p. 114-115]

Sn = a1 + a2 + … + an
Sn = an + an−1 + … + a1
Cada columna suma lo mismo, a1 + an (lo que uno sube, el otro baja), y hay n columnas: 2Sn = n(a1 + an) →
Sn = (a1 + an) · n2
así sumó Gauss de niño 1 + 2 + … + 100 = 101 · 50 = 5050 [p. 115]

8.1 · Idea de límite y límites laterales

Qué significalimx→a f(x) = L quiere decir que, cuando x se acerca a a (sin llegar a valer a), f(x) se acerca a L tanto como queramos.
Con precisión: para cada distancia ε > 0, por pequeña que sea, hay un δ > 0 tal que si 0 < |x − a| < δ, entonces |f(x) − L| < ε.
Lo que pase justo en a no importa: f(a) puede no existir o valer otra cosa. [p. 118]
Límites lateralesPor la izquierda limx→a⁻ f(x) (con x < a) y por la derecha limx→a⁺ f(x) (con x > a).
El límite existe si y solo si existen los dos laterales y coinciden:
limx→a f(x) = L ⟺ limx→a⁻ f(x) = limx→a⁺ f(x) = L [p. 118]
Ejemplof(x) = x2  si x ≤ 13x − 2  si x > 1: limx→1⁻ x2 = 1, limx→1⁺ (3x − 2) = 1 → limx→1 f(x) = 1 [p. 118]
Límites en el infinito y límites infinitoslimx→+∞ f(x) = L: al hacer x tan grande como queramos, f(x) se acerca a L (la gráfica tiene la asíntota horizontal y = L).
limx→a f(x) = +∞: cerca de a, f(x) se hace tan grande como queramos (asíntota vertical x = a).

8.5 · Continuidad

Definiciónf es continua en x = a si se cumplen a la vez:
1) existe f(a) (a está en el dominio);
2) existe limx→a f(x) y es un número;
3) limx→a f(x) = f(a).
Es continua en un intervalo si lo es en todos sus puntos: se puede dibujar «sin levantar el lápiz». Las funciones elementales son continuas en su dominio; en las de a trozos hay que mirar los puntos de unión. [p. 127]
Tipos de discontinuidadEvitable: el límite existe pero no coincide con f(a) (o f(a) no existe). Se arregla redefiniendo f(a).
De salto finito: los laterales son números distintos.
De salto infinito: algún lateral es ±∞ (hay asíntota vertical).
Esencial: algún lateral no existe. [p. 128]
Ejemplos de clasex2 − 4x + 2: no existe f(−2), pero limx→−2 (x − 2) = −4 → evitable (sería continua definiendo f(−2) = −4; la libreta pone 0, y así seguiría siendo discontinua)

10.2 · Curvatura y puntos de inflexión

El signo de la segunda derivadaSi f″(x) > 0, la pendiente f′ va aumentando: la función es convexa ∪.
Si f″(x) < 0, es cóncava ∩.
Los puntos de inflexión son donde cambia la curvatura: allí f″(a) = 0 (si existe) y f″ cambia de signo.
Criterio de la segunda derivada: si f′(a) = 0 y f″(a) < 0, máximo; si f″(a) > 0, mínimo. [p. 145; Llanera]
Ejemplof(x) = x3 − 6x2 + 9x + 1: f′ = 3x2 − 12x + 9 = 3(x − 1)(x − 3) · f″ = 6x − 12
f″(1) = −6 < 0 → máximo (1, 5) · f″(3) = 6 > 0 → mínimo (3, 1) · f″ = 0 en x = 2 y cambia de signo → inflexión (2, 3)

11.1 · Variables bidimensionales

Una variable estadística bidimensional (X, Y) recoge dos características de cada individuo: horas de estudio y nota, temperatura y ventas, altura y peso… Interesa saber si están relacionadas y, si lo están, usar una para predecir la otra. [Llanera, 2.1-2.2]

TablasTabla simple: las parejas (xi, yi), con su frecuencia si se repiten.
Tabla de doble entrada: los valores de X en las columnas, los de Y en las filas y en cada casilla cuántas veces aparece esa pareja.
Las distribuciones marginales son X e Y por separado (las sumas de filas y columnas); las condicionadas, una de ellas solo para un valor fijo de la otra (una fila o una columna).
Tipos de relaciónFuncional: una variable se obtiene exactamente de la otra con una fórmula (lado y área de un cuadrado).
Estadística: hay una tendencia, pero no una fórmula exacta (estatura y peso). De esta se mide el sentido (positiva/negativa) y la intensidad (fuerte/débil).

Nube de puntosCada pareja es un punto del plano. Si la nube se agrupa alrededor de una recta, hay correlación lineal: positiva si la recta crece, negativa si decrece; fuerte si los puntos están muy cerca de ella. Si la nube es redondeada, no hay correlación lineal.

11.2 · Covarianza y coeficiente de correlación

ParámetrosMedias y desviaciones marginales: x, y, sx, sy. El punto G(x, y) es el centro de gravedad de la nube.
Covarianza: sxy = Σ fi(xi − x)(yi − y)N = Σ fi xi yiN − xy
Coeficiente de correlación de Pearson: r = sxysx · sy [Llanera, 2.3-2.4]
Por qué funciona la covarianzaG parte el plano en cuatro cuadrantes. Si la nube va hacia arriba, casi todos los puntos están en el 1.º y el 3.º, donde (x − x) y (y − y) tienen el mismo signo: los productos son positivos y la covarianza también. Si baja, la covarianza es negativa.
Pero depende de las unidades; al dividir entre sxsy se obtiene r, que no tiene unidades y siempre está entre −1 y 1.
Cómo se interpreta rr = ±1: dependencia funcional (los puntos están en una recta) · |r| cerca de 1: correlación fuerte · cerca de 0: débil o nula · el signo es el sentido.
El coeficiente de determinación R2 = r2 dice qué parte de la variación de Y explica la recta: con r = 0,9, R2 = 0,81, un 81 %.

r = 9,611,84 · 8,4 ≈ 0,963: correlación positiva y muy fuerte · R2 ≈ 0,93

11.3 · Rectas de regresión

Recta de regresión de Y sobre XEs la recta que mejor se ajusta a la nube para predecir y a partir de x: la que hace mínima la suma de los cuadrados de las distancias verticales de los puntos a la recta (mínimos cuadrados). Pasa por G y su pendiente es sxy/sx2:
y − y = sxysx2(x − x)
Para predecir x a partir de y se usa la de X sobre Y: x − x = sxysy2(y − y).
Las dos se cortan en G; cuanto más fuerte es la correlación, más cerca están (si |r| = 1 coinciden; si r = 0 son perpendiculares). [Llanera, 2.5]
Fiabilidad de una predicciónEs fiable si |r| es alto y el valor está dentro del rango de los datos o cerca. Extrapolar lejos es peligroso: la tendencia puede cambiar.
Seguimos con horas y notaY sobre X: y − 5 = 9,611,84(x − 5,4) → y = 0,811x + 0,622

Entonces se ajusta una parábola y = ax2 + bx + c con la calculadora u hoja de cálculo (modo QUAD o «línea de tendencia polinómica de grado 2»), y se comparan los R² de los dos ajustes: el que tenga R² más cercano a 1 se ajusta mejor. [PD 26-27]
Correlación no es causalidadQue dos variables estén muy correlacionadas no significa que una cause la otra. Las ventas de helados y los ahogamientos están correlacionados… porque los dos aumentan en verano (una tercera variable, la temperatura).

Probabilidad

12.1 · Experimentos aleatorios y sucesos

VocabularioUn experimento es aleatorio si no se puede predecir su resultado aunque se repita en las mismas condiciones (lanzar un dado).
Espacio muestral E: el conjunto de todos los resultados posibles. Dado: E = {1, 2, 3, 4, 5, 6}.
Suceso: cualquier subconjunto de E. «Sacar par» = {2, 4, 6}. Elemental: un solo resultado. Seguro: E. Imposible: ∅.
Operaciones con sucesosUnión A ∪ B: ocurre A o B (o los dos).
Intersección A ∩ B: ocurren A y B a la vez.
Contrario A: ocurre cuando no ocurre A.
Incompatibles: no pueden ocurrir a la vez, A ∩ B = ∅.
Leyes de De Morgan: A ∪ B = A ∩ B, A ∩ B = A ∪ B

12.2 · Probabilidad. Regla de Laplace

Frecuencia relativa y probabilidadSi se repite un experimento muchas veces, la frecuencia relativa de un suceso (veces que ocurre / veces que se repite) se estabiliza alrededor de un número: su probabilidad (ley de los grandes números). Así se estiman probabilidades cuando no hay simetría (una chincheta, un dado trucado).
Propiedades: 0 ≤ P(A) ≤ 1 · P(E) = 1 · P(∅) = 0 · P(A) = 1 − P(A)
P(A ∪ B) = P(A) + P(B) − P(A ∩ B) (la intersección se habría contado dos veces); si son incompatibles, se suman.
Regla de LaplaceSi todos los resultados son equiprobables:
P(A) = casos favorablescasos posibles
Sacar un as de una baraja española de 40 cartas: 440 = 110.
EjemploSe lanzan dos dados. Hay 6 · 6 = 36 resultados equiprobables. Suma 7: (1,6), (2,5), (3,4), (4,3), (5,2), (6,1) → 636 = 16. Al menos un 6: el contrario es «ningún 6», 2536, así que 1 − 2536 = 1136

12.4 · Probabilidad condicionada

DefiniciónLa probabilidad de A sabiendo que ha ocurrido B:
P(A | B) = P(A ∩ B)P(B)  (P(B) ≠ 0)
Al saber que ha ocurrido B, el espacio muestral se reduce a B y de A solo cuenta lo que está dentro de B.
Despejando sale la regla del producto: P(A ∩ B) = P(B) · P(A | B).
IndependenciaA y B son independientes si saber que ha ocurrido uno no cambia la probabilidad del otro: P(A | B) = P(A), es decir, P(A ∩ B) = P(A) · P(B).
Sacar bolas con reemplazamiento da extracciones independientes; sin reemplazamiento, dependientes.
No confundir independientes con incompatibles.

12.5 · Árboles, probabilidad total y Bayes

Diagramas de árbolEn un experimento compuesto (varias etapas) cada rama lleva la probabilidad de esa etapa, condicionada a lo anterior. Así:
· la probabilidad de un camino es el producto de sus ramas (regla del producto);
· la de un suceso que se alcanza por varios caminos es la suma de esos caminos.
Las ramas que salen de un mismo nudo suman 1.
Probabilidad total y teorema de BayesSi A1, …, An son incompatibles y cubren todo E (las ramas de la primera etapa), sumando los caminos que llevan a D:
P(D) = P(A1) P(D | A1) + … + P(An) P(D | An) (probabilidad total)
Y para saber la probabilidad de una «causa» sabiendo el resultado, se usa la definición de condicionada: el camino entre el total:
P(Ai | D) = P(Ai) P(D | Ai)P(D) (teorema de Bayes)
En el árbolP(D) = 0,6 · 0,03 + 0,4 · 0,05 = 0,018 + 0,020 = 0,038
Se encuentra una pieza defectuosa. ¿Probabilidad de que venga de B? P(B | D) = 0,0200,038 ≈ 0,526: aunque B fabrica menos, es más probable que la defectuosa venga de B.
